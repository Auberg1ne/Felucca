Development build from validated checkpoint 29bc277. Current uncommitted compatibility work is excluded.

  1. Load the optional four-track demo and eight user samples
  2. Start simulator — ordinary startup

Click Switch on, then play the on-screen keys or your computer keyboard (Z X C V B N M). Left/right arrows select tracks. In the demo: track 1 = factory SAMPLE, 2 = factory GRAIN, 3 = SAMPLE USR8, 4 = GRAIN USR8.

Experimental Worker startup: click Prepare, wait, then click Start audio. Optional and default-off.

Limitations

  • Editor connection is read-only. Browser sample upload/erase and backup restore into the simulator are unavailable.
  • Five factory IDs currently share three distinct materials. Demo user samples are synthetic test tones.
  • Browser saves are local to this browser and URL/port. Use a dedicated playtest origin; do not import valuable project data.
  • Startup glitches remain possible. Automated playback does not prove audible quality, deadline safety or FM-1 compatibility.
  • Do not use this build with physical hardware. No hardware validation or flashing was performed.
